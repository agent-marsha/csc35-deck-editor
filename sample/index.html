01

PID Control

Teaching a machine to hit a target.

Measure the error. React to it three ways: to how big it is, to how long it has lasted, and to how fast it is changing.

Intro to Autonomous RoboticsCS 460/5608 SLIDES
02

Push hard enough to arrive fast, and you sail right past.

A single hard push is a guess. Control is about reacting to what the measurement is actually doing.

03

Proportional: how far off am I right now?

uP = Kp e(t)

Big error, big push. Small error, small push — like a spring, or a driver steering harder the farther they drift from the lane.

Fast, but it relaxes exactly when work is still left to do.

04

Integral: the controller looks backwards in time.

uI = Ki ∫ e(τ) dτ

It stores up the error the system sees over time. As long as the error never reaches zero, the integral keeps increasing in magnitude.

05

Derivative: the slope tells you when to brake.

uD = Kd de/dt

Derivative reacts to the rate of change, so it pulls back before arrival instead of after the overshoot.

Damping, paid for in advance.

06

P is fast. I is exact. D is calm.

P onlyQuick, but it lands short and rings.
P + IHits the target exactly — after a long wobble.
P + I + DFast, exact, and settled.
07

Each gain fails in its own direction.

Gain
Too low
Too high
Kp
Sluggish — creeps toward the target.
Overshoots, then oscillates.
Ki
A permanent gap that never closes.
Slow, rolling oscillation; integral windup.
Kd
Nothing restrains the overshoot.
Twitchy — amplifies measurement noise.
Usual order of attack: raise Kp until it responds briskly, add Ki to erase the offset, add Kd only if it still rings.
08

The whole controller is one line.

u(t) =
Kp e(t)Error now — react
+

One measured error, three gains. Start with P, add I to remove the offset, add D when you need calm.
